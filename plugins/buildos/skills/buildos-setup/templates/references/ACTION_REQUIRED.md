# Human handoffs

Use only when a human action is needed. Existing authorization persists; do not add repeated
approval requests to routine reversible work.

- State what to do and why.
- Give exact steps and expected results, with prerequisites and ordering.
- Include a final verification and likely failure symptoms/fixes.
- Put sensitive values in secure service configuration, not chat or commits.

Verify UI/CLI details before giving exact instructions; label uncertain steps. Distinguish
missing information from permission and name the externally consequential action when needed.
